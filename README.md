# 🎙️ Discord Neural TTS Voice Bot (Slash Commands + Free Neural TTS)

Современный Discord бот на Node.js (v18+), работающий на **Слеш-командах (`/`)** и использующий **бесплатный нейросетевой TTS (Microsoft Edge Neural TTS)** без подписок и API-ключей!

Бот подключается к голосовому каналу и автоматически озвучивает сообщения участников (отлично подходит для людей с выключенным микрофоном или без него).

---

## 🌟 Основные возможности

- 🤖 **Слеш-команды (`/`)**: Интеграция с нативными слеш-командами Discord (`/join`, `/leave`, `/say`, `/voice`, `/skip`, `/help`).
- 🧠 **Бесплатный TTS (RHVoice + Microsoft Edge Neural TTS)**:
  - 🇷🇺 **Русские нейро-голоса**: `ru-RU-SvetlanaNeural` (Женский), `ru-RU-DmitryNeural` (Мужской).
  - 🇷🇺 **Локальные RHVoice**: 15 мужских и женских голосов, включая `Yuriy`.
  - 🌐 **Google TTS**: Резервный стандартный голоc.
  - 💰 **100% бесплатно**, не требует API-ключей или кредитных карт!
- 🗣️ **Авто-озвучка участников голосового канала**: Просто отправьте сообщение в чат, находясь в канале с ботом.
- 📋 **Очередь воспроизведения**: Фразы зачитываются по очереди без наложения звука.
- 🧹 **Очистка текста**: Автоматически удаляет URL-ссылки, блоки кода, упоминания, эмодзи и служебные символы.
- ⏱️ **Склейка сообщений**: Быстрые сообщения одного человека озвучиваются одной фразой.
- 🎧 **Личные настройки**: Каждый участник выбирает свой голос и скорость.
- 🇷🇺 **18 русскоязычных голосов**: 15 локальных RHVoice, 2 Edge Neural и Google TTS fallback.
- 🧠 **RHVoice**: Лёгкий CPU-синтез без API-ключей и отдельного sidecar-контейнера. Поддерживает личные скорость, тон и громкость.
- ⚙️ **Расширенная admin-панель**: Управление реакцией 🎙️, автоотключением, именами, muted-режимом, склейкой и лимитом текста.
- 🗄️ **SQLite**: Личные и серверные настройки хранятся в транзакционной базе с WAL-журналом.

## 🛠️ Установка и запуск

### Docker / Komodo

Создайте Stack из этого репозитория, выберите `compose.yaml` и добавьте секретную
переменную окружения `DISCORD_TOKEN`. База SQLite хранится в постоянном Docker
volume `voice_bot_data` и не теряется при пересоздании контейнера.

```bash
docker compose up -d --build
docker compose logs -f bot
```

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка бота в Discord Developer Portal
1. Зайдите на [Discord Developer Portal](https://discord.com/developers/applications).
2. Создайте приложение, откройте вкладку **Bot** и скопируйте **Bot Token**.
3. На этой же вкладке включите **Privileged Gateway Intents**:
   - ✅ **MESSAGE CONTENT INTENT**
   - ✅ **SERVER MEMBERS INTENT**
4. Во вкладке **OAuth2** -> **URL Generator**:
   - Scopes: `bot`, `applications.commands`
   - Permissions: `Connect`, `Speak`, `Send Messages`, `Read Message History`, `Add Reactions`
   - Перейдите по сгенерированной ссылке и добавьте бота на сервер.

### 3. Настройка файла `.env`
Создайте `.env` файл в корневой директории:
```env
DISCORD_TOKEN=ваш_токен_бота_из_developer_portal
```

### 4. Запуск
```bash
npm start
```
*При первом запуске бот автоматически зарегистрирует слеш-команды (`/`) в Discord.*

## 🎮 Слеш-команды (`/`)

| Команда | Описание |
| :--- | :--- |
| `/join` | Подключить бота к вашему текущему голосовому каналу |
| `/leave` | Отключить бота от голосового канала |
| `/say <текст>` | Озвучить произвольный текст |
| `/voice <выбор>` | Выбрать один из доступных русскоязычных голосов |
| `/settings [voice] [speed] [pitch] [volume]` | Интерактивный личный TTS-профиль |
| `/admin` | Интерактивная панель администратора |
| `/skip` | Пропустить текущую фразу |
| `/help` | Справка по боту |
